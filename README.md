# LogicQuestBot 💡

[A bot](https://t.me/logicquestbot) that will help you develop logical thinking without leaving your favorite messenger!

> This bot is my school project work.

## How does it work?

1. 🔑 Register
2. ✍ Complete at least one task every day
3. 🥇 Earn points and compete with others

## What was implemented?

* 🌐 Language selection
* 🔔 Daily reminders
* ✍ Three grades with 45 tasks each
* 🏆 Leaderboard and personal stats
* ✅ Two types of tasks: multiple choice or text input
